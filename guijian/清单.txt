# 东大文物古建 · 手帐清单
#
# 【怎么用】
#   1. 把照片放进同目录的 img/ 文件夹，文件名用 01.jpg 02.jpg 03.jpg ……（jpg / png / webp 都行）
#   2. 在下面按同样格式，一行写一处文物
#   3. 顺序 = 手帐翻页顺序 = 索引网格顺序，想调整就调行序，不用改名
#   4. 以 # 开头的行会被忽略，空行也忽略
#
# 【格式】
#   序号 | 名称 | 地点
#
#   名字里不要用竖线 | ，其余随便，可以有空格和标点
#
# 【示例 —— 请整段替换成你的真实清单】
#
01 | 大礼堂 | 四牌楼 · 中央大道
02 | 六朝松 | 四牌楼 · 梅庵北侧
03 | 孟芳图书馆 | 四牌楼 · 中央大道
